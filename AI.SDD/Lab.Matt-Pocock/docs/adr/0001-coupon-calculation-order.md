# ADR 0001: 折價券計算順序與邊界保護決策 (Coupon Calculation Order and Boundary Protection)

- 狀態: Accepted
- 日期: 2026-10-10
- 決策者: Matt Pocock Workflow Alignment

## 背景與問題描述 (Context)
在購物車結帳流程中，消費者可能同時套用多種類型的優惠券（例如全館 9 折百分比折扣券與滿千折百固定現折券）。
若無明確規範套用順序，不同順序將導致計算結果不一致（例如先折後打折 vs 先打折後折抵）。
此外，若總折扣金額超出購物車原始金額，需要定義系統行為以避免負數帳單或溢出。

## 決策選項 (Options Considered)
1. **選項 A**: 先扣滿額現折，剩餘金額再套用百分比折扣。
2. **選項 B (選用)**: 先依原始購物車小計套用百分比折扣，再扣除滿額固定折扣；最後實施 0 元下限防護。

## 決策原因 (Decision Outcome)
採用 **選項 B**：
1. **符合電商主流商業習慣**：全館折扣（百分比）通常以原始合格金額計算，滿額現折則視為最後抵扣憑證。
2. **避免小數點精度反覆縮放歧義**：百分比打折僅計算一次並四捨五入，後續固定折抵直接相減，保持純量計算精確。
3. **0 元溢出保護（Negative Total Protection）**：實付金額下限為 0 元，多出的折抵額直接作廢不找零，不拋出例外，確保結帳流程順暢體驗。

## 後果 (Consequences)
- 正面：
  - 折扣計算規則明確且確定（Deterministic），相同輸入保證相同輸出。
  - 純運算函式（Pure Function）無副作用，利於測試。
- 負面：
  - 消費者若有多張同類優惠券，需依券順序循序處理，需在規格中定義穩定排序或陣列順序保證。
