# Domain Documentation Configuration

## Strategy
- Mode: Single-context
- Glossary Location: `GLOSSARY.md` (root directory)
- Architecture Decision Records (ADR): `docs/adr/` (format: `0000-slug.md`)

## Principles
1. Maintain shared domain vocabulary in `GLOSSARY.md`.
2. Document significant architectural decisions in `docs/adr/`.
3. Use `/grill-with-docs` to sharpen domain terminology before implementation.
