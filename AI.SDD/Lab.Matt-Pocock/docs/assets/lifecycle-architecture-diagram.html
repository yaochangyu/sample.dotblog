Matt Pocock Skills Architecture · Diagram Design

全生命週期三軌閉環架構

涵蓋「功能交付內軌」、「持續架構演進外軌」以及「科學異常排查中繼軌」，以深模組接縫哲學貫穿全生命週期。

INNER LOOP · 功能交付內軌

嚴格五階段工程推進鏈條

  • 階段 0~1：環境配置與盤問對齊，消除商業模糊。
  • 階段 2~3：規格提煉為垂直工單，背景子代理並行跑 TDD。
  • 階段 4：雙軸代碼審查（Standards 軸 + Spec 軸）嚴格驗收。

OUTER LOOP · 架構演進外軌

持續掃描淺模組與架構摩擦力

  • 線上運行迭代後，主動進行 codebase 摩擦力掃描。
  • 產出視覺化 HTML 報告，辨識高耦合、低內聚的淺模組。
  • 透過盤問敲定方案，無縫回流至規格提煉進入重構交付。

DIAG LOOP · 異常排查中繼軌

科學診斷紀律與回歸保護

  • 嚴禁肉眼盲猜，先建立「秒級紅燈反饋迴圈」最小化重現。
  • 提出可證偽假說，單變數插樁驗證根本原因。
  • 鎖定公開接縫修復，經雙軸審查驗收後回歸生產環境。
