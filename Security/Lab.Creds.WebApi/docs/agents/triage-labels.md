# Triage Labels

| Canonical role | 本地 Status 值 | 意義 |
|---|---|---|
| needs-triage | needs-triage | 待維護者評估 |
| needs-info | needs-info | 待補充資訊 |
| ready-for-agent | ready-for-agent | 規格完整，可交由 agent 執行 |
| ready-for-human | ready-for-human | 需要人工實作 |
| wontfix | wontfix | 不處理 |

Skill 提及 triage 角色時，使用上述值；本地 tracker 不建立遠端標籤。
