# 05: 隔離 Client 操作權限與業務資料範圍

**What to build:** 每個已驗證呼叫服務只能執行核准操作並讀取或修改自己的業務資料；其他合作廠商即使持有相同 scope 也不能越權。

**Blocked by:** 02 — 呼叫服務取得 Token 並經可信入口呼叫 API。

**Status:** ready-for-agent

- [ ] 以兩個獨立 Client 與不同業務資料範圍展示允許和拒絕情境。
- [ ] API／scope 白名單限制可執行操作；Token 有效但缺乏必要權限時拒絕。
- [ ] 讀取與修改資料皆檢查業務資料範圍，不只在入口判斷 scope。
- [ ] 相同 scope 的 Client 不能操作其他合作廠商的資料。
- [ ] Body、查詢參數或路徑自行指定的組織／資料識別不能擴大已核准範圍。
- [ ] 授權判斷依已驗證 Client 身分，不使用未驗證的身分資訊；拒絕的写入不產生副作用。
- [ ] 授權資料來源與契約先確認；正向示範及越權整合情境可重現。
- [ ] 此票可在受控測試環境先於簽章票驗證業務授權，不將未具完整保護的入口當成正式接入完成。

對應驗收：AC-12。
