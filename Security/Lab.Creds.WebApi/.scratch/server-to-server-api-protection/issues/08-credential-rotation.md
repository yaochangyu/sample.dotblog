# 08: 不中斷的正常輪替與洩漏撤銷

**What to build:** 呼叫服務可在新舊憑證／簽章金鑰重疊期間持續合法呼叫，切換完成再退役舊金鑰；發現洩漏時不等待重疊期結束。

**Blocked by:** 07 — 60 秒撤銷與查證故障時拒絕處理。

**Status:** ready-for-agent

- [ ] 正常輪替重疊期與操作程序取得確認，mTLS 及請求簽章金鑰分開管理。
- [ ] 每 Client、每環境獨立配置私鑰，不共用呼叫服務身分或跨環境私鑰。
- [ ] 正常流程先登錄新憑證／公鑰、切換呼叫端，再退役舊憑證／公鑰。
- [ ] 在重疊期間以新舊配置完成合法呼叫；退役後舊配置不能繼續通過。
- [ ] 新憑證重新取得綁定自己的 Token；舊 Token 搭配新憑證被拒絕。
- [ ] 分別輪替 mTLS 與簽章金鑰，不因其中一者切換誤認另一者已同步更新。
- [ ] 洩漏時直接撤銷受影響 Client、Token、憑證或金鑰，最多 60 秒內阻擋，不等待正常重疊期。
- [ ] 提供整合驗證及可重現輪替／洩漏處理說明；文件不含真實憑證或私鑰。

對應驗收：AC-13，並沿用 AC-04。
