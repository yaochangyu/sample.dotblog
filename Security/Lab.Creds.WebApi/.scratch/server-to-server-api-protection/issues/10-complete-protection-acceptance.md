# 10: 完整接入流程與規格驗收

**What to build:** 內外部呼叫服務可依共同契約完成接入、合法呼叫、重試與輪替；同一整合測試邊界證明所有保護一起生效，没有漏驗的業務入口。

**Blocked by:** 06 — 業務操作重試與併發只提交一次；08 — 不中斷的正常輪替與洩漏撤銷；09 — 安全追查已驗證呼叫者。

**Status:** ready-for-agent

- [ ] 在已確認的主要整合測試邊界執行母規格 AC-01～AC-14，列出對應情境與實際可重現證據。
- [ ] 正常接入與錯誤流程一起涵蓋 Client Credentials、mTLS、Token 綁定、簽章、nonce、scope、資料範圍及業務去重。
- [ ] 所有業務入口含純查詢及寫入都執行必要請求保護，無繞過 Gateway、替代 API Key／Client Secret 或漏驗簽章的路徑。
- [ ] 以多 Client、多執行個體、併發及既有連線驗證隔離、防重放和撤銷，量測總撤銷延遲不超過 60 秒。
- [ ] 合法重簽重試不重做本地副作用，查證故障與拒絕請求不產生副作用。
- [ ] 驗證認證、業務操作、錯誤及診斷紀錄不洩漏 Token、私鑰或完整敏感 Body。
- [ ] 提供內外部服務可重現的 Client 登錄、憑證／簽章配置、取得 Token、呼叫、重試、輪替與洩漏撤銷說明。
- [ ] 明確列出已確認產品／參數及仍未完成事項，不以短期示範代替生產容量或跨系統 exactly-once 保證。
- [ ] 遵循已指定開發規則完成適用的 build、測試及型別檢查，不宣稱未執行的驗收通過。
