# 11: 管理介面與管理員身分驗證

**What to build:** 授權伺服器提供只給管理員使用的管理介面。管理員以專屬的用戶端憑證經 mTLS 驗證，並登錄為管理角色；未經管理員驗證的呼叫一律被拒絕，信任名單不會改變。管理員身分與 Client 身分完全分開：管理憑證不能用來取得業務 Token 或呼叫業務 API，Client 憑證也不能呼叫管理介面。這張票先建立後續登錄核准都要經過的管理入口，並以管理介面的拒絕與隔離行為作為可單獨驗證的成果。

**Blocked by:** 02 — 呼叫服務取得 Token 並經可信入口呼叫 API。

**Status:** ready-for-agent

- [ ] 管理介面只接受以專屬管理憑證經 mTLS 驗證的管理員；管理憑證的登錄方式及測試環境的管理員身分建立方式取得使用者確認（Spec 未定義，不自行假設預設值）。
- [ ] 無憑證、未登錄憑證或持 Client 憑證呼叫管理介面時被拒絕，信任名單不變（AC-15）。
- [ ] 管理憑證嘗試取得業務 Token 或呼叫業務 API 時被拒絕（AC-20）。
- [ ] 管理介面與業務 API 的驗證結果各自獨立，不共用已驗證呼叫者的判斷。
- [ ] 以真實 mTLS 與 HTTP 路徑驗證，不以永遠成功的替身取代管理員驗證；每個驗收項目至少對應一個 BDD Scenario（Feature、Scenario、Given、When、Then 用英文，步驟用中文）。
- [ ] 管理介面的路徑與回應格式為 lab 暫定值並標註「待使用者確認」；不實作 Gateway 相關項目。
