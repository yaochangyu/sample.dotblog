# 01: 統一的已驗證呼叫者與呼叫者類型（前置重構）

**What to build:** 把現有服務呼叫路徑的驗證結果，改為產出統一的「已驗證呼叫者」：包含呼叫者類型（目前只有服務）、已驗證身分與權限。業務授權與業務邏輯只依這個已驗證呼叫者判斷，不再直接依服務驗證的內部細節。這是不改行為的前置重構，為後續加入使用者路徑鋪路；現有的服務呼叫行為與全部測試維持不變。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 服務呼叫路徑驗證成功後，產出包含呼叫者類型（服務）、已驗證身分與權限的已驗證呼叫者；授權與業務處理改為只依它判斷（AC-D02）。
- [ ] 服務呼叫的接受與拒絕行為與現有完全一致：mTLS 綁定、請求簽章、nonce、撤銷、fail closed、冪等與稽核不變；現有完整測試套件 0 失敗、不得刪弱既有斷言。
- [ ] 驗證失敗時，請求宣稱的呼叫者類型與身分只能標為未驗證，不產出已驗證呼叫者。
- [ ] 新增一個回歸 Scenario，證明服務呼叫在重構後仍受完整保護（AC-D02）。
- [ ] 每個驗收項目至少對應一個 BDD Scenario（Feature、Scenario、Given、When、Then 用英文，步驟用中文）；沿用既有主要整合測試邊界，不新增測試介面。
- [ ] 詞彙使用 `GLOSSARY.md` 既有用語；新增「呼叫者類型」草稿定義，待 08 單統一補入詞彙表。
