# Server-to-Server API 保護

本詞彙表定義本專案中服務身分、授權與業務操作的共同用語，區分呼叫服務、服務所屬組織及單次請求。

## Language

### 呼叫者與權限

**呼叫服務**:
以自身身分呼叫業務 API 的內部或外部服務，不代表某位使用者。
_Avoid_: 使用者、合作廠商（指稱呼叫服務時）

**Client 身分**:
呼叫服務在本專案授權關係中的獨立身分，不是服務所屬組織，也不是憑證本身。
_Avoid_: 使用者帳號、API Key（指稱服務身分時）

**合作廠商**:
外部呼叫服務所屬的組織；合作廠商與其呼叫服務的 Client 身分是不同概念。
_Avoid_: Client（指稱組織時）

**業務資料範圍**:
呼叫服務獲准操作的資料集合，與獲准執行的操作種類分開。
_Avoid_: scope（指稱資料範圍時）

**已驗證呼叫者**:
身分已完成驗證的呼叫服務，不包含請求自行宣稱但尚未驗證的身分。
_Avoid_: 宣稱的 Client、未驗證呼叫者

**呼叫者類型**:
已驗證呼叫者所屬的種類，由通過的驗證路徑決定、不採信請求內容的宣稱；目前為「服務」與「使用者」。服務類型的身分為 Client 身分，使用者類型的身分為使用者。
_Avoid_: 角色、身分類別（指稱驗證路徑的種類時）、呼叫者身分（指稱類型本身時）

**使用者呼叫者**:
以使用者 Token 呼叫業務 API 的已驗證呼叫者，代表某位已登入的使用者（身分為使用者，不是 Client）；其驗證路徑不要求用戶端憑證與請求簽章，且不得以服務 Token 或服務憑證通過。與「呼叫服務」不同：使用者呼叫者不以服務身分代表自己，也不因此擁有服務的高權限。
_Avoid_: 使用者帳號（指稱已驗證呼叫者時）、服務（指稱使用者呼叫時）、呼叫服務（指稱使用者呼叫時）

### 信任名單與管理

**管理員**:
以專屬管理憑證經 mTLS 驗證為管理角色的身分，可核准、拒絕、退役與撤銷 Client 的憑證與簽章金鑰。管理員身分與 Client 身分分開：管理憑證不能取得業務 Token，也不能呼叫業務 API；管理介面與業務 API 的驗證結果各自獨立，不共用已驗證呼叫者的判斷。
_Avoid_: 管理者、超級使用者、已驗證呼叫者（指稱管理介面的呼叫身分時）

**登錄申請**:
Client 為其公開憑證或簽章金鑰進入信任名單而提出的申請，只含公開部分，狀態為待核准、已核准或已拒絕。申請本身不是信任；只有經管理員核准後，憑證或金鑰才進入信任名單並生效。
_Avoid_: 註冊（指稱申請時）、已登錄（指稱尚未核准的申請時）

**申請者**:
對登錄申請而言，經 mTLS 驗證為已登錄且有效的 Client 身分，只能替自己提出申請；它是申請當下的驗證結果，不採用申請內容宣稱的 Client，也不等同於已驗證呼叫者（業務 API 的呼叫驗證結果）。
_Avoid_: 申請人、宣稱的 Client（指稱已驗證的申請者時）

**持有證明**:
申請者證明自己持有所申請憑證或簽章金鑰私鑰的資料，由新私鑰對申請內容簽章產生；申請只含公開部分，因此必須附上持有證明，證明失敗的申請不建立待核准紀錄。表示方式為 lab 暫定值，待使用者確認。
_Avoid_: 私鑰（指稱持有證明時）、簽章（泛指申請內容的簽章時）

### 業務操作與重試

**業務操作**:
具有獨立業務意義的一次操作；同一操作可以有多次請求嘗試，但不因此成為多筆操作。
_Avoid_: HTTP 請求、nonce（指稱業務操作時）

**請求嘗試**:
為執行或重試業務操作而送出的一次 API 呼叫，不等同於一筆新的業務操作。
_Avoid_: 新業務操作（僅因重送請求時）

**穩定業務識別**:
在約定的業務範圍內辨識同一筆業務操作的識別，不因重新送出請求而改變。
_Avoid_: Idempotency Key、請求識別、nonce（視為穩定業務識別的同義詞時）

**業務內容**:
決定業務操作意義的資料，不包含每次請求嘗試可能改變的認證或簽章資訊。
_Avoid_: 完整請求（指稱業務內容時）

**本地業務副作用**:
本業務服務內由操作產生的持久業務變更，不包含其他服務或外部系統的變更。
_Avoid_: 跨系統提交、請求回應

**本地提交不重複**:
同一筆業務操作的本地業務副作用不因重試或併發而重複提交的保證。
_Avoid_: 防重放、跨系統 exactly-once

### 防重放

**防重放紀元**:
防重放判斷開始可信的時間點；簽章建立時間早於此時間的請求一律不接受，因為它們的一次性識別可能已在紀錄遺失前被使用過。紀錄遺失（重啟、被清空）時，紀元重設為當下。
_Avoid_: 重啟時間、nonce 過期時間

### 驗收證據

**紀錄型證據**:
只檢查 issue 紀錄文字或勾選狀態的 Scenario，標籤為 `@record`；用於決策與紀錄追溯，不證明系統行為。
_Avoid_: 行為驗證（指稱 `@record` Scenario 時）

**略過（非完成）**:
本 lab 刻意不實作而不納入驗收的項目（如 Gateway），以未勾選加刪除線標示，不計為已達成。
_Avoid_: 已完成、已勾選（指稱略過項時）
