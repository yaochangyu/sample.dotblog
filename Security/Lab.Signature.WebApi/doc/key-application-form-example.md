# API Key 申請單範例

這是搭配 `Lab.Signature.WebApi` 教學 Lab 的人工申請流程範例，不是系統本身提供或自動產生的
功能。合作夥伴應先透過申請文件向內部窗口提出需求，由內部人員完成審核後，再由管理員核發
API Key。

## 填寫範例

| 欄位 | 範例資料 |
| --- | --- |
| 申請單位／合作夥伴名稱 | 示範夥伴股份有限公司 |
| 聯絡窗口 | 王小明 |
| 聯絡方式（Email） | wang.xiaoming@example.test |
| 申請用途說明 | 每日同步付款通知，供內部對帳系統核對交易狀態 |
| 預計呼叫的 API 端點 | `POST /api/protected/orders`、`GET /api/protected/orders/{id}` |
| 預計上線時間 | 2026-10-15 |
| 申請日期 | 2026-09-23 |
| 審核人 | 李小華 |
| 審核結果 | 通過（2026-09-24） |

申請單應只記錄業務需求與審核結果，不要在申請單、一般 Email 或其他容易外流的位置記錄
`Secret`。`Secret` 是核發後交付給合作夥伴的機密資料。
